# Alibaba — командная викторина для урока

Игра в стиле Baamboozle. Класс делится на команды, команды по очереди открывают цветные плитки и отвечают на вопросы. За некоторыми плитками прячутся бонусы.

- **Очки за сложность:** лёгкий вопрос — 10, средний — 15, сложный — 20. На плитке очки не видны, их узнают, только когда плитку откроют.
- **15 бонусов (power-ups)**, которые срабатывают сразу при открытии плитки: Double points, Win 50 points, Win 5–25 points, Go to first place, Take 5–25 points, Others lose 5–25, Swap points, Other team wins 5–25, Give 5–25 points, No points, Lose 50 points, Lose 5–25 points, Go to last place, Reset your score, Reset all scores. Организатор может выключить бонусы совсем или оставить только нужные. Как в Baamboozle, очки могут уходить в минус (например, после «Lose 50 points»).
- **Два режима:**
  - **Baamboozle** (один экран): класс делится на команды, команды по очереди открывают плитки и отвечают вслух, ведущий нажимает ответ. Телефоны не нужны. Поле — ряды по 4 плитки: 16 или 24 плитки (бонусы входят в это число).
  - **Kahoot** (телефоны): каждый играет сам за себя. Игроки открывают сайт, вводят PIN с экрана (или сканируют QR-код), придумывают ник и выбирают аватарку-животное. Организатор нажимает «Старт». Вопрос и 4 ответа появляются у всех на телефонах; чем быстрее верный ответ, тем больше очков: до 1000 за вопрос, как в Kahoot (`очки = (1 − (время ответа / таймер) / 2) × 1000`, ответ быстрее 0,5 с — сразу 1000). Организатор может завершить вопрос раньше — кто не успел, получает 0. После вопроса на экране столбики: сколько человек выбрало каждый ответ, процент верных ответов и кто ответил быстрее всех; потом таблица лидеров, в конце пьедестал.
- **Создать игру можно только с компьютера.** С телефона сайт открывается только для входа по коду.
- **Предметы и темы с поиском.** У каждой темы своя картинка-логотип. Сейчас в базе 5908 вопросов. В каждой теме ровно 16 или 25 вопросов: одной темы хватает на целое поле 4 × 4. Вопросы не повторяются от игры к игре: сайт запоминает (в браузере), какие вопросы уже были, и сначала берёт новые, а повторяет только когда новые закончатся.
  - *Школьная программа, 7 класс:* каждая тема — параграф учебника с его названием, вопросы составлены по тексту параграфа; все темы предмета идут одним списком:
    - Физика — 39 тем по 16 вопросов (Башарұлы Р. и др., «Атамұра», 2025);
    - История Казахстана — 47 тем по 16 вопросов (Омарбеков Т. О. и др., «Мектеп», 2025);
    - Всемирная история — 25 тем по 16 или 25 вопросов (Алдабек Н. А., Макашева К. Н., Байзакова К. И., Аманкулова Б. А., «Всемирная история (1640–1900)», «Мектеп», 2-е издание 2026 года; двойные параграфы — одна тема);
    - Биология — 63 темы по 16 вопросов (Соловьёва, Ибраимова, Алина, «Атамұра», 2025);
    - География — 43 темы по 16 вопросов (Каратабанов Р. и др., «Алматыкітап», 2025);
    - Русская литература — 26 тем по 16 вопросов (Савельева В., «Русская литература», 7 класс, 2025): статья учебника и само произведение — одна тема.
    - Русский язык — 32 темы по 16 вопросов (Сабитова З., «Русский язык», 7 класс, 2025): один урок (§1–32) — одна тема.
  - *Дополнительные курсы:* English Pre-Intermediate (76 тем по 16 вопросов: каждая тема — урок учебника Tim Falla, Paul A Davies «Solutions Pre-Intermediate», 3rd edition, Oxford University Press, — Introduction и Units 1–9, уроки A–H: лексика, грамматика, тексты для чтения, стратегии) и English C2 Proficiency (16 тем по 16 вопросов, очень сложные вопросы уровня CPE: инверсия, сослагательное наклонение, редкая лексика, идиомы, фразовые глаголы, трансформации).
- **Окно победы как в Baamboozle**: кубок, итоговая таблица с медалями, фанфары и аплодисменты, конфетти. В окне крутится по кругу случайное смешное видео — одно из 20 (GIPHY); кнопкой 🔀 можно сменить. Если интернета нет, вместо видео танцуют 3D-персонажи.
- **Игровое поле как в Baamboozle**: сверху полоса с командами и очками (ходящая команда выделена синим), синие плитки в шахматном порядке, справа круглые кнопки меню, звука и полного экрана.
- **Ники и аватарки**: 36 аватарок-животных — дракон, лев, тигр, жираф, панда, единорог, акула и другие.
- Картинки результата: хлопушка за верный ответ, крестик за ошибку, будильник, когда время вышло.
- Таймер, 2–4 команды, 5 фонов, звуки, конфетти, итоговый пьедестал. Незаконченную игру можно продолжить, а игроки после перезагрузки телефона возвращаются в игру сами.

Сайт целиком статический: без сервера, без регистрации и без сборки.

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**. Название, например, `alibaba`, тип **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
3. Распакуйте архив и перетащите в окно **всё содержимое папки**: `index.html`, папки `css`, `js`, `data`, `fonts`, `vendor`, файлы `README.md` и `.nojekyll`. Файл `index.html` должен лежать в корне репозитория, а не внутри ещё одной папки. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу. Вверху появится адрес вида `https://ваш-логин.github.io/alibaba/`. Это и есть ваш сайт.

> Файл `.nojekyll` начинается с точки, и на компьютере он может быть скрыт. Если не получилось его загрузить, создайте его на GitHub: **Add file → Create new file**, имя `.nojekyll`, содержимое пустое.

## Как играть

**Организатор (на компьютере с проектором):**
1. Откройте сайт и нажмите **Создать игру** (или **Играть** на карточке нужной темы).
2. Выберите предмет, потом тему (или «Все темы»), потом настройки: режим, команды, число вопросов, таймер, фон и бонусы.
3. В режиме **Kahoot** на экране появятся PIN и QR-код. Когда все зашли, нажмите **Старт**.

Горячие клавиши организатора: `1`–`4` — выбрать ответ, `Пробел` — дальше, `F` — во весь экран, `M` — звук. Если навести мышь на счёт команды, появятся кнопки −5 и +5 для ручной правки очков.

**Игроки (на телефонах):** откройте тот же сайт, введите 6-значный код, придумайте ник и выберите аватарку. Можно просто навести камеру на QR-код.

## Как добавить свой предмет

1. Скопируйте файл `data/_shablon.js` и назовите копию, например, `data/chemistry-8.js`.
2. Впишите в него id предмета (латиницей), название, класс, группу (`group: 'school'` — школьная программа, `group: 'extra'` — дополнительные курсы), темы и вопросы. Формат вопроса:
   ```js
   [сложность, "Вопрос?", "ПРАВИЛЬНЫЙ ответ", "неверный", "неверный", "неверный"]
   ```
   Сложность: `1` — лёгкий (10 очков), `2` — средний (15), `3` — сложный (20). Правильный ответ всегда пишется **первым**, а в игре варианты перемешиваются сами.
   Логотип темы задаётся строкой `img: 'img/topics/имя.svg'`: положите картинку (svg, png или jpg) в папку `img/topics`. Если картинки нет, вместо неё показывается эмодзи из `icon`.
   Необязательно (сейчас ни в одном предмете не используется): чтобы разбить темы на разделы (как параграфы в главах учебника), добавьте каждой теме строку `section: 'Название раздела'`. Темы одного раздела должны идти подряд; тогда в списке появятся заголовки разделов и карточка «Весь раздел».
3. В `index.html` найдите блок `ПРЕДМЕТЫ` и добавьте строку:
   ```html
   <script src="data/chemistry-8.js"></script>
   ```
4. Загрузите изменённые файлы на GitHub. Новый предмет появится в списке, и поиск будет искать и по нему.

Если в вопросе ошибка (например, не хватает варианта), сайт не сломается: этот вопрос просто пропустится, а подсказка появится в консоли браузера (`F12 → Console`).

## Как работает связь с телефонами

Своего сервера у сайта нет. Организатор и телефоны соединяются через бесплатные публичные сервисы, сразу по трём каналам:

1. **PeerJS** (`0.peerjs.com`) — прямое соединение WebRTC;
2. **MQTT-брокер EMQX** (`broker.emqx.io`);
3. **MQTT-брокер HiveMQ** (`broker.hivemq.com`).

Телефон использует тот канал, который ответит первым. Если школьная сеть блокирует один из них, работают остальные. В лобби под QR-кодом цветные точки показывают состояние каналов: зелёная — работает, жёлтая — подключается, красная — недоступен.

**Если телефоны не подключаются:**
- проверьте, что на компьютере организатора есть интернет и хотя бы одна точка зелёная;
- попробуйте подключить телефоны через мобильный интернет, а не через школьный Wi-Fi;
- в крайнем случае играйте в режиме Baamboozle (один экран) — ему интернет не нужен.

Сайт, открытый двойным щелчком как файл с компьютера, работает в режиме Baamboozle. Для телефонов он должен быть опубликован (например, на GitHub Pages).
